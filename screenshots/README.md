# Project Screenshots

This directory contains screenshots demonstrating the application functionality.

## Screenshots to capture:

1. **docker-compose-up.png** - Docker services starting up
2. **rabbitmq-management.png** - RabbitMQ Management UI
3. **api-testing.png** - API endpoint testing with Postman/curl
4. **console-output.png** - Consumer service output
5. **load-test-results.png** - Load test execution results

## How to take screenshots:

1. Start the application: `docker-compose up`
2. Open RabbitMQ Management: http://localhost:15672
3. Test API endpoints using Postman or curl
4. Run example scripts and capture console output
5. Execute load test and capture results

## Recommended tools:
- Postman for API testing
- Browser for RabbitMQ Management UI
- Terminal/Command Prompt for console output
